# twemoji.bin

The color emoji shown in chat: Twemoji 17.0.3 (https://github.com/jdecked/twemoji),
72x72 images re-encoded as lossless WebP and packed into one file by
`tools/pack_twemoji.py`.

Copyright 2019 Twitter, Inc. and other contributors; copyright 2024 Twemoji
contributors. Graphics licensed under CC-BY 4.0:
https://creativecommons.org/licenses/by/4.0/

# emoji-symbola.ttf

A subset of the Symbola font (emoji and symbol ranges only), used as a fallback
so emoji that egui's built-in font lacks still render (in the message box,
names, and anywhere color emoji aren't drawn).

Symbola, Copyright (C) 2007-2015 George Douros.
License: "Fonts are free for any use; they may be opened, edited, modified,
regenerated, packaged and redistributed."

# emoji-list.tsv

Emoji names, groups, search words and GitHub-style shortcodes for the picker,
generated by `tools/gen_emoji_list.py` from emojibase-data 17.0.0
(https://emojibase.dev). Copyright (c) 2017-2019 Miles Johnson. MIT License.
